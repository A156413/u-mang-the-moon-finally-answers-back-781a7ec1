The Moon finally answers back. After four billion years of wishes, howls, and 2 a.m. promises, it has one line to say to everyone staring up at it — and it is not the answer anybody wanted.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/moon-out python3 main.py
```

Writes the single-line entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` and prints it to stdout.
